BP-602 custom controls: answer key

sliders.html

  • Monthly budget: Issue. Interactive custom slider lacks slider role, accessible name, and programmatic value/range.
  • Storage allowance: No issue for this exercise. Exposes slider role, name, minimum, maximum, and current value; current value updates with interaction.
  • Support hours: Issue. Exposes slider role/name/range but omits current programmatic value and does not update it.

quantity.html

  • License seats: Issue. Interactive custom numeric control has no spinbutton role/name/value/range.
  • Training sessions: No issue for this exercise. Exposes spinbutton role, name, min/max, and current value; value updates.
  • Guest passes: Issue. Has role/name/range but omits current programmatic value.

navigator.html

  • Design resources: Issue. Keyboard-operable tree-like node lacks programmatic treeitem role and expanded/collapsed state.
  • Engineering resources: No issue for this exercise. Exposes treeitem semantics, name, hierarchy level, and expanded state; state updates.
  • Research resources: Issue. Exposes treeitem role/name but omits expanded/collapsed state despite supporting the interaction.

Boundary used: each target is interactive, but none is an accordion, ordinary button, checkbox, combobox, link, radio button, select, show/hide control, toggletip, or tooltip. This makes the examples better candidates for the generic name/role/state/value BP-602 rule.
