BP-602 Catch-all Answer Key

energy.html

  • July: Issue. Focusable custom chart object has no programmatic role or accessible name.
  • August: Issue. It is interactive but exposed as an image, so interactive semantics/state are missing.
  • September and October: No issue for this exercise. They expose an interactive role, meaningful name, and pressed state.

workspaces.html

  • 4A: Issue. Custom spatial marker lacks role and accessible name.
  • 4B: Issue. Option role/name are exposed but selection state is missing.
  • 4C, 4D, 4E: No issue for this exercise. Relevant identity and state are exposed.

comfort.html

  • Cool: Issue. Focusable custom control lacks a programmatic role.
  • Mild: Issue. Slider has min/max but omits its current value.
  • Balanced, Warm, Very warm: No issue for this exercise. Role, name, range, current value and meaningful value text are exposed.

These examples intentionally use unusual custom chart objects, spatial markers, and a custom preference scale so the target defects fit the generic BP-602 name/role/state rule rather than a component-specific rule.
