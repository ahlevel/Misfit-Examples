BP-602 answer key

Plan Builder

  • Monthly budget: Catch-all issue. Interactive slider lacks role, accessible name, and programmatic range/value.
  • Storage allowance: No issue for this exercise. Name, slider role, range, and value are exposed.
  • Support hours: Catch-all issue. Slider role/name/range exist, but current value is missing.
  • Advanced pricing options: Show/hide-specific issue. It reveals/hides content but does not expose aria-expanded. Use the show/hide BP-602 rule.

Quantity Setup

  • License seats: Catch-all issue. Custom numeric control lacks spinbutton role/name/range/value.
  • Training sessions: No issue for this exercise. Spinbutton role, name, range, and current value are exposed and updated.
  • Guest passes: Catch-all issue. Role/name/range exist, but current programmatic value is missing.
  • Shipping and fulfillment: Accordion-specific issue. The accordion header expands/collapses a panel but omits aria-expanded. Use the accordion BP-602 rule.

Resource Navigator

  • Design resources: Catch-all issue. Keyboard-operable tree-like node lacks treeitem role and expanded state.
  • Engineering resources: No issue for this exercise. Treeitem semantics and expanded state are exposed and updated.
  • Research resources: Catch-all issue. Treeitem role/name exist but expanded/collapsed state is missing.
  • Save workspace: Button-specific issue. It performs a button action but lacks button semantics. Use the button BP-602 rule.

Testing intent: each page mixes generic catch-all BP-602 defects with at least one defect that should route to a component-specific BP-602 rule.
